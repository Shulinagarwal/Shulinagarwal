## Featured projects

### [Cortex — AI Agent Workspace](https://github.com/Shulinagarwal/Cortex)

A full-stack workspace with a LangGraph tool-calling orchestrator for document Q&A, web search, and code generation. Includes streamed responses, conversation summaries, opt-in persistent memory, and a GitHub MCP connector.

**Stack:** React · Node.js · Express · LangGraph · Qdrant · MongoDB · Redis

### [RAGCache — Context-Aware Caching for RAG](https://github.com/Shulinagarwal/Rag-Cache)

A Python caching system with separate retrieval and generation layers. Combines semantic matching, context-stability checks, intent-aware cache decisions, tenant scoping, and Prometheus metrics to support reuse of LLM responses.

**Stack:** Python · Redis · FAISS · Sentence Transformers · Prometheus

### [PulseRoute — LLM Agent Evaluation Benchmark](https://github.com/Shulinagarwal/PulseRoute)

An infrastructure benchmark that evaluates agents on event routing, least-privilege access, message recovery, and deployment reconstruction after state loss. Includes **17 scored checks totaling 100 points**, a reference solution, and a separate submission runner.

**Stack:** Python · Terraform / OpenTofu · Docker · Lambda · SNS / SQS · DynamoDB · IAM · KMS

### [FrostPass — Agent Security and Recovery Benchmark](https://github.com/Shulinagarwal/FrostPass)

A benchmark for secure deployment across two emulated AWS accounts. Tests version-bound approvals, encrypted evidence, concurrent decisions, immutable receipts, and recovery from lost, stale, corrupted, or interrupted deployment state.

**Validation:** 35 scored capability groups · Recorded reference result of 100/100 · Five faulty application variants rejected

**Stack:** Python · Terraform · Docker · Lambda · S3 · DynamoDB · STS · KMS · EventBridge Scheduler

[Read the validation report →](https://github.com/Shulinagarwal/FrostPass/blob/main/tools/validation/VALIDATION.md)

## How I approach engineering

- Define observable behavior and clear acceptance criteria.
- Test failure paths, retries, and concurrency alongside the happy path.
- Keep permissions narrow and preserve data during recovery.
- Use execution traces and reproducible cases to explain failures.
- Report measured results with their scope and limitations.
